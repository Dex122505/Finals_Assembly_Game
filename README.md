# Group2_Blk4_Assembly

A collaborative Assembly language project by Group 2, Block 4.

---

## 📁 Branch Overview

| Branch | Purpose |
|--------|---------|
| `main` | Stable, final version of the project |
| `UI` | User Interface assets and screen designs |
| `DOCU` | Documentation, reports, and write-ups |
| `PROGRAM` | Core Assembly language program files |

---

## 🌿 Branch Details

### `main`
The default and stable branch. Contains the final, merged version of all components from the other branches. Only fully tested and reviewed code/files are merged here.

### `UI`
Contains all user interface-related files such as:
- Screen layout bitmap files (`.BMP`)
- Visual assets used in the program display
- Win/lose screen graphics and player sprites

### `DOCU`
Contains all documentation related to the project:
- Project reports and write-ups
- Design documents
- Member contributions and task breakdowns

### `PROGRAM`
Contains the core Assembly language source code and runtime files:
- `.ASM` source files
- Supporting executables (`.COM`, `.EXE`, `.OVL`)
- Program logic and game mechanics

## 🚀 How to Run

1. Ensure you have a DOS environment or DOSBox installed.
2. Clone the repository:
   ```
   git clone https://github.com/Dex122505/Group2_Blk4_Assembly.git
   ```
3. Navigate to the `PROGRAM` branch for source files.
4. Run using DEBUG.COM or the appropriate DOS executor.
